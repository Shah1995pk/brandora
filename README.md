## 🛠️ How to Customize

### 1. **Update Your Information**
   - Open `index.html`
   - Replace placeholder text with your actual information
   - Update phone number, email, location in the contact section

### 2. **Add Your Logo & Photos**
   - Create an `assets` folder in your repository
   - Add your logo as `assets/logo.png` (50x50px recommended)
   - Add your profile picture as `assets/profile.jpg`

### 3. **Add Portfolio Images**
   - Create `assets/portfolio/` folder
   - Add your work images: `work-1.jpg` through `work-6.jpg`
   - Update portfolio item titles and descriptions

### 4. **Add Client Logos**
   - Create `assets/clients/` folder
   - Add client logos: `client-1.png` through `client-4.png`
   - Update client names and descriptions

### 5. **Update Social Links**
   - Find the social media links section in the contact area
   - Replace `#` with your actual social media URLs
